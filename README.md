# Первый Нежилой — сайт-презентация

Локальный лендинг для оператора коммерческой недвижимости в Ярославле. React + TypeScript + Vite, обычный CSS без Tailwind, без внешних картинок (все визуалы — CSS).

## Запуск

```bash
npm install
npm run dev
```

`npm run dev` сам откроет сайт в браузере (флаг `--open` в скрипте `dev`). Если браузер не открылся автоматически — откройте адрес из терминала (`http://localhost:5173` или следующий свободный порт) вручную.

## Команды

- `npm run dev` — запуск дев-сервера с автооткрытием браузера и HMR
- `npm run build` — проверка типов (`tsc -b`) и продакшн-сборка в `dist/`
- `npm run preview` — локальный просмотр собранной сборки из `dist/`

## Структура

```
index.html        — мета-теги, favicon (инлайн SVG)
src/main.tsx       — точка входа
src/App.tsx         — все секции и данные сайта
src/styles.css      — все стили (токены, layout, секции)
```

## Где что редактировать

**Объекты недвижимости** — массив `OBJECTS` в начале `src/App.tsx`. Каждый объект — объект типа `CommercialObject` со строковыми полями (цена, аренда, доходность и т.д. уже отформатированы как строки — так проще держать формат `"9,8 млн ₽"` под контролем). Поле `categories` отвечает за фильтр-пилюли наверху блока "Объекты", поле `visual` — за CSS-плейсхолдер картинки (`street` / `office` / `warehouse` / `retail` / `plan` / `corner`).

**Контакты** — телефон и email захардкожены в компонентах `Header` и `Footer` в `src/App.tsx` (поиск по `8 (900)` и `hello@perviy-nezhiloy.ru`).

**Остальной контент** (сценарии, услуги, кейсы, аналитика, FAQ, показатели доверия) — тоже типизированные массивы в блоке `// ===== DATA =====` в начале `App.tsx`.

**Цвета, отступы, радиусы** — токены в `:root` в начале `src/styles.css`. Палитра монохромная (чёрный/белый/серый), радиусы скруглений почти нулевые — если нужно вернуть тёплую палитру или скруглённые карточки, всё меняется через эти переменные.

## Форма заявки

Сейчас форма в разделе "Получите расчет по объекту" (`FinalCtaSection` в `App.tsx`) при отправке просто показывает локальное состояние "заявка собрана" (`preventDefault` + `setSubmitted(true)`) — никуда не отправляется. Чтобы подключить реальный приём заявок:

1. В обработчике `onSubmit` вместо `setSubmitted(true)` сделать `fetch` на свой бэкенд/Telegram-бота/CRM-вебхук с данными формы.
2. Показывать `setSubmitted(true)` только после успешного ответа, а на ошибку — выводить сообщение об ошибке (сейчас такого состояния нет, его нужно добавить).

## Перед продакшеном

- Заменить телефон, email и мессенджеры в `Header`/`Footer` на настоящие.
- Заменить показатели в блоке "Доверие через цифры" (`TrustSection`) на фактические — сейчас там условные значения с явной оговоркой в тексте секции.
- Подключить форму к реальному приёму заявок (см. выше).
- Проверить актуальность цифр доходности по объектам — это ориентировочные расчётные сценарии, не гарантия доходности (на сайте есть обязательная звёздочка и дисклеймер).
